# INDEX POLIMAR® — Plastic Mulching Film Corporate Website

A premium, modern, responsive corporate website built for **INDEX POLIMAR®**, a manufacturer and supplier specializing in **plastic mulching film and agricultural plastic products** located on Sanawad Bhikangaon Road, Hirapur.

---

## 🌟 Key Features

- **Pearlcon Design Architecture**: Powered by Space Grotesk, IBM Plex Sans, IBM Plex Mono typography, deep navy background tokens, and glossy amber primary action buttons.
- **Product Range & Specification Modals**: Interactive product showcase featuring Black Mulching Film, Silver-Black Mulching Film, Transparent Solarization Film, Colored Spectrum Film, and Customized Mulching Film options with pop-up spec sheets.
- **Interactive Orbit Hub**: Hero section featuring an animated orbit hub graphic with floating metric glassmorphism cards.
- **Manufacturing Process & Quality Assurance**: 5-stage production process pipeline and quality indicators.
- **Media Gallery with Lightbox**: Categorized masonry gallery supporting full-screen image previews.
- **Lead Generation & Quotation System**: Complete contact enquiry form with instant feedback toast and Google Maps location embed.
- **WhatsApp Integration**: Floating multi-number WhatsApp contact trigger.

---

## 🛠️ Technology Stack

- **Framework**: React 18 + Vite
- **Styling**: Tailwind CSS v4 + Custom Pearlcon CSS Variables
- **Icons**: Lucide React Icons
- **Typography**: Google Fonts (Space Grotesk, IBM Plex Sans, IBM Plex Mono)

---

## 🚀 Getting Started

### Installation
```bash
# Clone the repository
git clone https://github.com/infoharry99/indexpolimar.git

# Navigate into the workspace
cd indexpolimar

# Install dependencies
npm install

# Start local dev server
npm run dev
```
